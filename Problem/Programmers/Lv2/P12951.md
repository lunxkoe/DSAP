# JadenCase 문자열 만들기

## 새로 알게 된 것들
- 자바 String은 []로 접근할 수 없음
    - string.charAt(index)로 접근
- 특정 문자열를 대소문자로 변경하는 것은 string.toLowerCase() | string.toUpperCase()
    - 특정 문자를 대소문자로 변경하는 것은 Character.toLowerCase(character) | Character.toUpperCase(character)

## 문제 파악에 어려웠던 점
- 공백 문자 처리에 대한 명확한 이해가 부족
    - 연속된 공백의 경우 하나의 공백으로 처리해야하는 줄 알고, 연속된 공백 처리에 대해서 고민함
    - 하지만 공백 문자가 연속해서 나올 수 있다는 조건만 있을 뿐, 공백을 하나로 처리하라는 말은 어디에도 없었음

## 문제를 풀기 위해서 핵심이라고 생각한 것들
- 단어의 시작이라는 것을 알아낼 수 있는 방법들
    - 처음 생각한 것: 공백을 기준으로 split(" ")을 하여 String[]로 단어를 구분
    - 실제 핵심:
        - 가장 처음은 문자 시작으로 확인 및 변경 (isFirst = true => isFirst = false)
        - **공백을 만나면 다음 문자를 만나는 순간 단어의 첫 글자로 판단 (isFirst = true)**

- 그렇다면 숫자는 어떻게 처리하는데?
    - 숫자에 대해서 lowerCase() / upperCase()를 적용해도 숫자는 그대로 유지되기 때문에 상관이 없음
    - **단어의 시작이면 uppserCase() 아니면 lowerCase()를 부르면 그만**
