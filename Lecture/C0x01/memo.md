# 기초 코드 작성 요령

## 시간, 공간 복잡도

### 시간 복잡도
- 컴퓨터는 1초에 3~5억개 정도의 연산을 수행 가능함

#### 시간 복잡도 (Time Complexity)
- 입력의 크기와 문제를 해결하는데 걸리는 시간의 상관관계

#### 빅오 표기법
- 주어진 식을 값이 가장 큰 대표항만 남겨서 나타내는 방법
    - O(N): 5N + 3
    - O(N^2): 6N^2 + 20N
    - O(NlogN): NlogN + 30N
    - O(1): 5, 6, 36 - 수행 시간이 항상 일정하다는 의미일뿐 (입력의 크기(N)과 관계 없음

#### 크기 비교
- O(1) < O(logN) < O(N) < O(NlogN) < O(N^2) < O(2^N) < O(N!)

#### N의 크기에 따른 허용 시간 복잡도 (보통 3 ~ 5초)
- N <= 11 | O(N!)
- N <= 25 | O(2^N)
- N <= 100 | O(N^4)
- N <= 500 | O(N^3)
- N <= 3,000 | O(N^2logN)
- N <= 5,000 | O(N^2)
- N <= 1,000,000 | O(NlogN)
- N <= 10,000,000 | O(N)
- 그 이상 | O(logN) / O(1)

### 공간 복잡도

#### 공간 복잡도 (Space Complexity)
- 입력의 크기와 문제를 해결하는데 필요한 공간의 상관관계

#### 기억할 것
- 512MB = 1.2억개의 int(4바이트)

## 정수 자료형

### 자료형의 크기
- int: ~21억 ~ +21억 / unsigned int: 42억
- int를 넘어가는 크기의 수를 저장해야하는 경우 long long(8Byte)를 사용

### Integer Overflow
- int의 양수 범위를 넘어가는 경우 음수가 되는 현상 (Underflow: 음수 범위를 넘어가는 경우 양수가 되는 현상)

## 실수 자료형

### float, double
- float (4Byte)
- double (8Byte)

### 주의할 점
- 실수의 저장/연산 과정에서 반드시 오차가 발생할 수 밖에 없음
- double에 long long 범위의 정수를 함부로 담으면 안됨
    - double: 유효 숫자 15자리
    - long long: 유효 숫자 19자리
- 실수를 비교할 때는 등호를 사용하면 안됨
    - 1e-12 == 10^-12
    - 1e9 == 10^9
    - ex) abs(a) < 1e-12
