# 연결 리스트

## 정의와 성질

### 정의
- 원소를 저장할 때, 그 다음 원소가 있는 위치를 같이 저장하는 방식으로 저장하는 자료구조
- 배열과의 차이
    - 배열은 원소 자체만을 저장함
    - 연속된 물리적인 메모리 공간이 할당되어서 인덱스로 접근할 수 있음
    - 연결 리스트는 (원소, 다음 원소의 위치)로 저장함 == 노드
    - 연속되지 않은 물리적인 메모리 공간이 할당되고, 노드의 다음 원소의 위치(주소)를 기반으로 접근할 수 있음

### 성질
1. k번째 원소를 확인/변경하기 위해 O(k)가 필요함
2. 임의의 위치에 원소를 추가/임의 위치의 원소 제거는 O(1)
3. 원소들이 메모리 상에 연속해있지 않아 Cache hit rate 낮지만 할당이 다소 쉬움

### 종류
1. 단일 연결 리스트(data, next)
2. 이중 연결 리스트(data, next, prev) - STL list
3. 원형 연결 리스트(data, next, prev)
    - 시작 노드와 마지막 노드가 연결되어있음

### 배열 vs 연결 리스트
| | 배열 | 연결 리스트 |
|---|---|---|
| k번째 원소의 접근 | O(1) | O(K) |
| 임의 위치에 원소 추가/제거 | O(N) | O(1) |
| 메모리 상의 배치 | 연속 | 불연속 |
| 추가적으로 필요한 공간(Overhead) | 필요없음 | O(N) / prev, next |

## 기능

### 제공되는 연산
1. 임의의 위치에 있는 원소를 확인/변경 - O(N)
    - 첫번째 주소의 주소만 알고 있기 때문에 반드시 순차적으로 접근해야함

2. 임의의 위치에 원소를 추가 - O(1)
    - 배열처럼 데이터를 뒤로 밀필요가 없음
    - 노드 간의 연결 정보만 변경하면 됨 - O(1)
    - **단, 추가하고 싶은 원소의 위치를 찾기 위해서는 순차적으로 접근해야함 - O(N)**

3. 임의의 위치에 원소를 제거 - O(1)
    - 원소를 추가하는 과정과 동일
    - 노드 간의 연결 정보만 변경하면 됨 - O(1)
    - **단, 삭제하고 싶은 원소의 위치를 찾기 위해서는 순차적으로 접근해야함 - O(N)**

### 어디에 사용할까?
- 메모장의 커서
    - 커서 위치에 글자를 추가하거나 제거하는 명령을 수행해야함
    - 배열을 사용할 경우에는 속도가 매우 느림
    - **추가/삭제할 위치를 이미 알고 있는 경우에는 추가/삭제가 O(1)으로 매우 빠름**

## STL list

### stl_list_example.cpp
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    list<int> L = {1, 2};
    list<int>::iterator t = L.begin();
    
    L.push_front(10); // 10 1 2
    cout << *t << '\n'; // 10

    L.push_back(5); // 10 1 2 5

    L.insert(t, 6); // t가 가리키는 곳 앞에 6을 삽입 - 10 6 1 2 5
    t++; // 현재 t가 가리키는 값은 2

    t = L.erase(t); // t가 가리키는 값 제거, 그 다음 원소의 위치를 반환 - 5의 위치를 반환

    cout << *t << '\n';

    for (auto i : L) {
        cout << i << ' ';
    }
    cout << '\n';

    for (list<int>::iterator it = L.begin(); it != L.end(); it++) {
        cout << *it << '\n';
    }

    return 0;
}
```

## 연습 문제

### 손코딩 문제 1
- 문제
    - 원형 연결 리스트 내의 임의의 노드 하나가 주어졌을 때, 해당 list의 길이를 효율적으로 구하는 방법

- 해결
    - 동일한 노드가 나올 때까지 계속 다음 노드로 가면 됨
    - 공간 복잡도 O(1)
    - 시간 복잡도 O(N)

### 손코딩 문제 2
- 문제
    - 중간에 만나는 두 연결 리스트의 시작점들이 주어졌을 때, 만나는 지점을 구하는 방법

- 해결
    - 일단 두 시작점 각각에 대해서 끝까지 진행시켜서 길이를 구하고,
    - 다시 두 시작점으로 돌아와서 더 긴 쪽을 둘의 차이만큼 앞으로 먼저 이동시켜놓고,
    - 두 시작점이 만날 때까지 두 시작점을 동시에 한 칸씩 전진
    - 공간 복잡도 O(1)
    - 시간 복잡도 O(A + B)

### 손코딩 문제 3
- 문제
    - 주어진 연결 리스트 안에 사이클이 있는지 판단

- 해결
    - 플로이드 사이클 찾기 알고리즘
        - 한 칸씩 가는 커서와 두 칸씩 가는 커서를 활용
        - 사이클이 있을 경우 두 커서는 반드시 만나게 됨
    - 공간 복잡도 O(1)
    - 시간 복잡도 O(N)
